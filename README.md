# Welcome to the CKBuilders project tracker!

This is a resource for CKBuilders to share what they're building with live demos and MVPs. These can be shared with other developers in the community who can review and offer feedback. A table containing the respective projects and their statuses will also be maintained here.

## Request project review

### For CKBuilders
If you have a project you would like to receive feedback on, please follow these steps:
1. Create an issue, adhering to the following style guidelines:  
 a. Title field: Enter the name of your project in the Title field, and a minimal description of what it does. Example: _Pocket Node: a mobile light client wallet implementation_  
 b. Body field: copy and paste the following text and add in your details as appropriate    
	+ **Project Summary:** Explain in more detail what your project does. One paragraph.  
   + **Tools used:** List the tools or sdk's you are using to build. Example: `ckb-js-vm`, `ckb-ccc`, etc.  
	+ **Current features:** List the current things your project can do now  
 	+ **Planned features:** List what you intend to add to your project  
  	+ **Deployed on:** Testnet? Mainnet?  
	+ **Link to repository:** Include a link to the project repository.  
   + **Link to hosted version of project:** Include a link for reviewers or community to test  
   + **Screenshots:** Include screenshots of the project UI  
   + **Request for feedback:** What is it that you are requesting from reviewers? Be detailed and specific. For example:  
   		+ **Problems**: What obstacles are you facing currently? For specific errors, first report them on the CKBuilders telegram channel or on the relevant tool's repository.  
   		+ **Review**: Explain what you wish for reviewers to do. Example: Check the concept and implementation is viable? Suggestions for where current features could be improved?  
   		+ **Guidance**: Explain what kind of advice you are looking for. Example: How best could this project move forwards? What new features would improve its edge?  
3. Submit the issue and share with the CKBuilders' co-ordinator (Neon) and on the CKBuilders telegram channel  
  
   ### For Reviewers

   Please tag yourself into an issue to tag your team member if there is a project that you would like to advise on. Please provide detailed advice and encouragement, explaining your thought process and providing practical examples where possible. This will benefit not only the reviewee but the wider community.
